The Capture Loop

Knowledge flows through four stages in a continuous loop. Every stage is automatic except optional review in Obsidian.

Automatic

1. Capture

Agents write atomic capture files to inbox/{agent}/ as they work. Decisions, learnings, progress, interactions, observations.

Automatic

2. Summarize

Session hooks append breadcrumbs to the daily log on PreCompact and SessionEnd. No manual log writing.

Scheduled

3. Distill

BrittBot cron processes inbox captures nightly. Creates structured notes with frontmatter and [[wikilinks]]. Updates indexes.

Automatic

4. Retrieve

Agents read _index/ at session start for context. Query knowledge/ and notes/ on demand during sessions.

Habits Cheat Sheet

The system is designed to run with zero manual effort. These optional habits maximize capture quality.

WhenDoWhy
Ending a Claude session Type /exit instead of closing the terminal Gives SessionEnd hook time to write the daily log breadcrumb cleanly
After a big decision Say "capture that decision to BrittBrain" Prompts Claude to write a capture file immediately instead of waiting
Morning Glance at _index/active-context.md in Obsidian See what the system thinks you're working on — correct if wrong
Weekly Browse the Obsidian graph view Spot cross-domain connections the distillation agent created
After a Telegram conversation with BrittBot Nothing — BrittBot auto-captures Captures flow through inbox/brittbot/ automatically
